First public release of **ego bridge** — use your Mac's ego-lite browser from remote AI agents.

- Native Mac menu-bar App with secure pairing, reconnect, Agent-space activity and shared CLI control.
- Linux `ego-browser` shim with stdin/output forwarding, screenshot/file return and request-id result queries.
- Install the Agent skill with `npx skills add gwen0x4c3/ego-bridge@v2.2.0 --skill ego-bridge`.
  The skill includes the full App/service setup; installing the skill alone does not install the runtime.
- Source, setup and examples: https://github.com/gwen0x4c3/ego-bridge#for-you

Choose the macOS archive matching your CPU (`arm64` or `x86_64`). Python 3.9+ and the
separately installed official ego-lite browser are required. Apps are ad-hoc signed,
not Developer ID signed or notarized. Source builds are supported.

The Linux archive includes its installer, service, shim, skill and documentation.
`SHA256SUMS` contains checksums for all downloadable runtime archives.

Extra HTTP headers are verified per page within one CLI invocation; they do not persist
across invocations or propagate to new pages. Agent activity reports spaces and bridge
commands, not individual clicks or model reasoning.
