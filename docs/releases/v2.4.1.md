# Drag-to-install Mac downloads

- Apple Silicon (`arm64`) and Intel (`x86_64`) DMGs are now built and uploaded automatically.
- Open the DMG and drag EgoBridge.app to Applications. For App + CLI + Linux setup,
  the existing one-command installer and Homebrew remain available.
- Every DMG is checked for image integrity and mounted read-only to verify the App
  signature/version and Applications shortcut before publishing. SHA256SUMS includes DMGs.

Packaging uses macOS tools and free standard GitHub Actions runners for this public
repository. No paid packaging service or Apple Developer membership is required.
The App remains ad-hoc signed, not notarized; macOS may require first-launch approval.
Python and the separately installed official ego-lite browser are still required.
