# One command, both machines

```bash
curl -fsSL https://raw.githubusercontent.com/gwen0x4c3/ego-bridge/main/install.sh | bash
```

On Mac, installs the prebuilt App/CLI and opens a keyboard-driven setup wizard:

- Select an SSH alias with ↑/↓ or enter user@host.
- Install the Linux runtime over SSH, without remote GitHub access.
- Optionally pair/connect both endpoints automatically through their CLIs.

On Linux, the same command installs the CLI/service directly. Credentials are kept.
The installer now supports offline archives, custom ports and background service startup.

The README is available in English and 中文 and focuses on user setup. Homebrew remains
available in gwen0x4c3/homebrew-tap; Homebrew 7 requires one-time package trust.

The official ego-lite browser remains a separate Mac prerequisite. Mac builds are
ad-hoc signed, not notarized. Quit an old running App before upgrading.
