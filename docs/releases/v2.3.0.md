Install ego bridge without building it yourself.

**Mac App + CLI + Python:**
```bash
brew install --cask gwen0x4c3/tap/ego-bridge
open -a EgoBridge
```

**Mac or Linux, automatic platform detection:**
```bash
curl -fsSL https://github.com/gwen0x4c3/ego-bridge/releases/latest/download/install.sh | bash
```

The standalone installer requires Python (Mac 3.9+, Linux 3.7+) and Linux OpenSSL.
It selects the prebuilt archive, verifies SHA-256, preserves pairing, and installs
App/CLI or Linux CLI/service. `--version v2.3.0`, `--prefix DIR` and `--no-start` are supported.

Linux Homebrew users can install `gwen0x4c3/tap/ego-bridge-agent`, then start it with
`brew services start gwen0x4c3/tap/ego-bridge-agent`.

The official ego-lite browser is still installed separately on the Mac. Mac Apps are
ad-hoc signed, not Developer ID notarized. Quit an old running App before upgrading.
The Homebrew tap periodically syncs Releases; maintainers can trigger Sync immediately.
