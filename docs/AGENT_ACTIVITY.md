# Agent 活动观察

当前接入 ego-browser 公共 SDK 的 `listTaskSpaces()`，读取 Agent 创建/控制的空间、
控制权和最近页面标题。popup 每约 3 秒查询一次；只有面板展开时才查询，关闭面板后清空
内存快照。查询前检查 ego-lite 是否正在运行，不通过活动观察主动启动浏览器。

- **Agent 控制 / 你在控制**：空间控制权，不表示 Agent 此刻一定在执行操作。
- **最近页面**：`recentTabTitles` 中最近的非空标题，不等同于当前激活页面。
- **桥接命令执行中**：本桥接核心收到、尚未结束的命令数。
- **桥接命令空闲**：没有正在执行的桥接命令；不推断其他 Agent 是否仍在运行。

观察不创建、认领或接管空间，也不读取用户普通窗口的页面内容。名称和标题仅用于当前
用户的本地面板/状态输出，不写入日志或历史文件，不传给 Linux 服务。

已检查的 0.6.2.9 CLI 帮助、SDK 用法及安装包中的 CLI 调用方，没有提供可订阅的
全局动作进度接口。因此当前不显示“正在点击哪个按钮”或“正在思考什么”，也不从脚本
正文猜测动作。未来若公开事件接口，可以在相同活动区接入。
